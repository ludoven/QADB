## 批量与桌面交互

- 应用页可从文件夹递归安装 APK（含子目录），固定执行设备，逐个显示完成进度和失败详情；目录选择期间也禁止重复启动。列表和网格支持双击打开应用信息。
- 文件页支持拖入本地文件或目录，整批使用拖入时的设备和目录；上传期间切换目录不会改变后续文件的目标。与 ADB push 一致，同名目标可能被覆盖。
- 日志支持拖动多选、右键复制和全选。复制使用选择时的内容快照，不随筛选或缓冲区淘汰而变成其他日志；切换设备会清空选择。再次点击当前快捷筛选可取消该条件。
- 命令库按 UTF-8 读取，避免系统默认编码导致中文乱码。
- 无线连接继续使用现有入口，保留地址校验、配对与连接历史。

### 验证批量功能

常规回归：`./gradlew :composeApp:desktopTest -Pqadb.includeAndroidHelpers=false`。

真机测试 `Pr9DeviceSmokeTest` 默认跳过。通过环境变量 `QADB_PR9_DEVICE` 指定测试设备序列号，`QADB_PR9_APKS` 指定仅含 `one.apk`、`two.apk` 的测试目录；包名分别为 `com.ludoven.qadb.pr9test.one` 和 `com.ludoven.qadb.pr9test.two`，应使用无权限、无业务代码的专用测试 APK。测试要求这两个包未安装，执行后卸载它们并删除本次创建的临时设备目录。不要使用业务 APK 作为此测试的输入。

此测试验证真实安装结果、上传文件内容及上传期间切换目录；拖放手势、双击和日志菜单仍需桌面交互检查。

## AI Agent 执行边界

- 输入区可选问答、计划或执行。问答与计划默认仅发送用户输入文本给所配置的 RESPONDER Provider；用户为单次任务明确打开“设备证据”后，可读取所选设备的当前界面文字与状态并发送给该 Provider，仍不执行设备动作或截屏。执行默认使用截图引擎，可在设置中显式启用实验 Artemis。启用后若其就绪检查失败，发送会被阻止，不会静默回退到截图引擎。
- 截图执行模式的每个设备动作决策都必须包含最新设备截图；所用 BRAIN 模型需通过 L3 视觉与工具调用能力测试。问答和计划模式仅要求可回答文本的 RESPONDER Provider。
- 截图任务开始时冻结标准/谨慎授权策略；谨慎模式对文本输入、强停应用和重启设备增加逐次确认。界面存在密码输入框但输入目标无法定位时拒绝自动输入。
- ADB 最终动作出口在点击、滑动、输入与按键前重新读取前台应用包名；与当前观察不一致或无法读取时拒绝动作并要求重新观察。这是观察到执行之间的防错校验，不是完整的跨应用授权范围。
- 模型配置和已通过的能力验证会持久保存；只在 Provider 地址、模型、能力声明或凭据发生变化后要求重新验证。
- OpenAI 兼容 Provider 可返回标准 `tool_calls`、旧式 `function_call` 或严格 JSON 工具调用；普通文本和多动作响应仍会被拒绝。
- 模型只能选择打开应用、点击、输入、滑动、按键、等待、完成、询问用户或阻塞，不接收任意 shell/ADB 指令。
- 点击和滑动使用 `0..1000` 归一化坐标，由本地执行层映射到真实设备分辨率并校验截图 revision。
- 执行20步后进入软限制，在第20、25、30、35步检查实际页面变化和目标进展；第40步后强制交还用户。
- 危险操作由本地策略确认；结果不明确的发送、删除或购买动作不会自动重放。
- 工作台的观察状态只读，任务运行时按需获取画面；Token 卡区分任务累计消耗与最近一次请求的输入占用，Provider 未提供的数值不推算。
- 任务历史在本地保存最多 100 字标题、设备引用、公开动作摘要、结束状态与可选的前段 ID；不保存截图、输入正文、模型内部上下文或完整对话。重启后可检索查看，打开历史不会自动执行设备操作。可从已结束且停止状态明确的记录创建新执行段；需先在设备上核对上段效果，并使用原设备提交新的目标。新段重新观察，不重放旧动作或授权。已结束、停止明确且没有后续执行段引用的记录可逐条确认删除；删除仅作用于历史摘要，独立审计日志与指标保留。旧审计日志不会自动变成历史记录。
- 每次发送都会创建独立运行；运行中可起草下一条指令，但不会注入当前执行。直接发送作为新任务，不继承旧对话上下文；从历史创建新执行段才保留前段 ID。
- Artemis 的高风险审批只有在 Bridge 提供动作、目标、摘要、设备、任务版本和有效期时才可放行；审批卡显示影响并提供允许一次、拒绝和停止。停止只有在 worker 清理完成且无在途设备动作时才确认；否则显示未确认。进程内及重启后的未决 Artemis 会话均阻止同设备新任务，可从历史页重新核查，不会自动重放操作。
